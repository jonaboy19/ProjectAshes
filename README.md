# Rising Ashes — Master Light Novel Project

This repository is the master storage location for the revamped Rising Ashes light novel project.

## Current Canon Direction

Rising Ashes now follows the revamped canon only. The old convoy/cart breakout version is retired unless the user explicitly chooses to recover a specific idea.

The story follows Sugo Wataro from a naive village boy in Aramori into a deeper dark-fantasy war story involving the Heavenly Way, elemental blessings, unclaimed children, Church manipulation, trauma-induced awakenings, Thal'ner, Vorrag, Rift mysteries, and Sugo's gradual path toward defying Heaven.
