NPC interruption and animation handoff

Interactive design sketch for one resident interrupted during daily life. It is a transition model derived from the current Rising Ashes state design and a published high-budget open-world AI paper; it is not a runtime replay and the timings below are schematic.

Choose the interruption

Abrupt override

One state immediately stops the old clip and starts the new task. The seat/tool/speech/route reservation may remain owned; the rig can jump from sitting or walking into combat/dialogue; old movement may still be active in another controller.

Coordinated handoff

Request the higher priority task, let the current owner exit through an explicit transition and cleanup, then enter the new task. Restore or replace the interrupted goal only after checking that it is still valid.

Rules to carry into implementation

  • Give each actor one movement owner. Independent, non-conflicting upper-body gestures may layer over locomotion when the rig filters support them.
  • Keep high-priority events responsive, but let states release seats, counters, held objects, speech, attack reservations, and path ownership safely.
  • Separate the actor's current activity, transition state, and next requested behavior so a blocked change does not erase what should resume.
  • Use authored transitions when needed: stop walking, turn toward the event, stand from a chair, put down or release a tool, raise a guard, settle back to idle.
  • Bind world changes such as taking an item, placing a cup, or claiming an anchor to explicit contact points in the action, then verify the object and hand actually meet.
  • Test normal entry, interruption, interrupted transition, actor removal, and resume on every rig family that uses the state.
