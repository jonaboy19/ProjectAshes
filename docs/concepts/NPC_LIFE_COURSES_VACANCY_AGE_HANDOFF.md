# LifeCourses vacancy age eligibility — Codex handoff

Date: 30 September 2026
Branch: `gpt/living-world-integration`
Scope: age correctness for residents selected or generated by `_find_or_create_worker()` when filling an open career seat. No `ensure_person()`, Life/Careers integration, API or save-format changes.

## Change

- The existing one-pass resident scan now skips living, unemployed same-settlement candidates under 16 using `_age_years(person, WorldSim.day)`. Candidate order and all other existing eligibility logic are preserved.
- The fallback worker still receives the existing random age of 18–40, but `birth_day` is now relative to the current `WorldSim.day`, so the generated age is correct when the vacancy is filled at any point in a save.
- Age is the only qualification modeled here. A 16-year-old can still fill any open seat because profession, training and title qualifications are not represented by this selector.

## Verification and limits

Static source review and `git diff --check` only. No parser, runtime vacancy, save/load or behavior check was run. Existing residents younger than 16 are skipped only when selecting a new vacancy occupant; no broader employment migration is performed.
