# Region map readability — 2 October 2026

Originally developed in isolated `gpt/living-world-integration`; now ported to `gpt/character-feel-finish` on Claude's published 1983bfeb source. Coach travel and fare rules are preserved. The port requires a new runtime capture.

The actual `world_map.gd` now clusters nearby already-visible point places below 0.6 px/m, using high-priority representatives and count badges. Tapping a cluster centres/zooms it; drawing and touch picking share the same marker layout so hidden members cannot steal taps. Selected places remain separate. Area labels retain their existing treatment, Discovery still owns eligibility, and undiscovered locations are never admitted by clustering. Important labels avoid represented marker bounds and the player marker; a blocked lower label tries above its icon.

`kingdom/tools_qa/capture_region_map.gd` renders the real Control with seed 1066 and a fresh Discovery model. It checks member-count conservation and cluster tap zoom, waits for the existing terrain bake and exports a screenshot via ASHES_MAP_CAPTURE. Actual Compatibility/OpenGL capture succeeded at 1600×900 on the RTX 4070 laptop. Initial capture showed a stack of overlapping icons and a capital label across the player; the updated capture shows count badges and a clear Kingsreach label above its icon. This harness does not open the full game scene or include every Life lore/session state. Touch-device behaviour and phone cost remain unverified.

Known limitations: cluster membership is greedy, not transitive; identical coordinates at high zoom can still overlap; selected labels retain their forced display rule. Layout currently recomputes on draws/picks and uses a pair scan; profile densely discovered regions before a mobile release, and cache by shown/filter/zoom/centre/selection state if necessary. Cluster count is number of represented points, not population. No persistent cluster IDs or new save fields.

The previous seeded atlas export supplied 20 settlements, 19 road connections, 3 river polylines, 353 sites and 129-square terrain/forest/water grids for the older 8 km world. Claude's current world is 12 km wide. The exporter now samples `WorldGen.WORLD_HALF` dynamically; regenerate rather than reusing the old atlas or illustrated map as geographically exact. It is authoring output with hidden places; never serve it as player intelligence. Runtime map discovery is preserved. Full terrain restyle, intelligence-report UI, settlement detail routes and the user's earlier traversal/combat/stealth requirements remain active.

During isolated project import two generic floor() calls in utility_brain.gd failed inference under warnings-as-errors. They now use typed floorf(), preserving float arithmetic. Subsequent world export and map harness compiled and ran. Import also changed many asset .import files and produced .uid sidecars; those incidental files are excluded from this patch. The import process completed. Capture exit logs include resource/texture leak messages requiring separate cleanup investigation; successful screenshot output does not prove clean teardown.
