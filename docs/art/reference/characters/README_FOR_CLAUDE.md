# Rising Ashes character references

Six transparent PNG turnaround sheets, 1536 x 1024, generated with the built-in OpenAI image generation tool on 2026-09-28. Each sheet contains front, left profile, and back views. PROMPTS.json records the exact prompts. Style direction: the user-supplied warm medieval town reference.

Farmer, baker, merchant, blacksmith, healer, and guard. These are 2D modeling references, not rigged 3D assets. Clothing, anatomy, accessory positions and poses can differ slightly between generated views; reconcile those details in Blender before modeling. Use the front view as the main identity reference. For image-to-3D tools, use one isolated view rather than feeding three figures as one subject.

All six PNGs have alpha channels; outer-corner and inter-view gap samples were confirmed fully transparent. Preserve original alpha when exporting. No game scripts, scenes, existing assets or settings were changed.
