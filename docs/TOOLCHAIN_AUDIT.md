# Codebase audit: keep or replace (2026-10-01)

Scope: `kingdom/scripts/` and `kingdom/autoload/` at origin/claude/focused-curie-m09hbd (about 170,000 lines of GDScript in 18 folders). This is a recommendation only; **no game code was changed.**
Method: line, function and TODO counts with `awk`/`grep` over the sparse worktree, per-file reads of the head comments, and Serena (`get_symbols_overview`, `find_symbol`, `find_referencing_symbols`) to confirm usage. "Max func" is the longest function in lines (approximate: the last function in a file includes trailing constants). Zero TODO/FIXME markers and no untyped `var x =` in any audited file, so the debt below is structural, not sloppiness.
"Work saved" is a rough estimate in agent-sessions or owner-days of work NOT spent (negative = migration costs more than it saves). Treat it as ordering, not a promise. Nothing was profiled on the S22 here.

## Dead weight to confirm and prune (one task, one commit)
Autoloads in `kingdom/project.godot` with no script users: `GUIDE`, `DialogueManager`, `GameplayCueManager` (GodotGAS), and the three `QuestWeaver*` autoloads (reached only by `get_node_or_null`). Editor plugins enabled with no users: `road-generator`, plus the ones above. Each autoload adds a parse and `_ready` at boot on the S22. **Measure boot time before and after on the phone**, and check `gdUnit4` tests do not depend on them. Do not do it on a branch other sessions are editing without telling them (project.godot is a conflict hotspot).

## Top recommendations by work saved
1. **Crash reporting**: Play vitals plus file logging now, Sentry for beta builds next (about 5 days of own tooling avoided; the installer already exists).
2. **Localisation**: move the 192 UI literals into `strings.csv` keys (about 3 days saved against a later rewrite).
3. **LimboAI for new combat, companion and Soulbeast AI only** (3 to 4 days: no behaviour-tree runtime to build). Keep the utility brain for villagers.
4. **Debug Draw 3D** for nav, NPC and streaming visualisation (about 1 day per overlay).
5. **Prune dead autoloads and plugins** (about 2 days of upkeep and merge noise, plus boot time to be measured).
