# Perf pass 2026-09-29

## Tools
- Overlay: Calinou godot-debug-menu (MIT, addons/debug_menu, credited in kingdom/CREDITS.md), enabled in project.godot.
  `scripts/core/perf_overlay.gd` (autoload `PerfOverlay`) creates it lazily: F3 on desktop, hidden 3-finger tap on mobile,
  `--perf` on the command line. Cycles hidden, compact, detailed. OFF by default (nothing instantiated until toggled).
  Extra panel: draws, primitives, objects, script process/physics ms, node count, skinned count, memory.
- QA shots print `[perf] fps draw_calls objects primitives process_ms physics_ms nodes skinned`.
  Extra flags: `--census` (who owns visible skeletons), `--drawcensus` (visible geometry by owner/mesh, tris),
  `--ablate[=script.gd/Node]` (hide each child in turn, prints draws/prims it costs).
- xvfb note: fps and process_ms are software-render frame time (TIME_PROCESS is the whole frame step), not script cost. Use draws/prims/skinned.

## Changes
1. critter.gd: visual cull. Beyond 60 m (small animals) / 130 m (large) x Quality range (LOW 0.55) the model is hidden and its AnimationPlayer paused. Hens were 130 of the 188 skinned meshes at the gate.
2. ambient_life.gd: chickens/pigeons/ducks/geese per group scaled by tier (LOW about 45%, min 1).
3. scripts/core/distance_cull.gd: 0.5 s timer hides + pauses gate guards (settlement_builder) and station NPCs (village_services) beyond 110 m x range.
4. settlement_builder.gd: houses with a single LOD (Blender, 4 surfaces, 4.5k tris) were one town-wide MultiMesh, drawn whole even behind the camera. Now 100 m cells (WIDE_CELL). Gate prims 340k -> 278k.
