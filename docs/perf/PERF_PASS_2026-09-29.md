# Perf pass 2026-09-29

## Tools
- Overlay: Calinou godot-debug-menu (MIT, addons/debug_menu, credited in kingdom/CREDITS.md), enabled in project.godot.
  `scripts/core/perf_overlay.gd` (autoload `PerfOverlay`) creates it lazily: F3 on desktop, hidden 3-finger tap on mobile,
  `--perf` on the command line. Cycles hidden, compact, detailed. OFF by default (nothing instantiated until toggled).
  Extra panel: draws, primitives, objects, script process/physics ms, node count, skinned count, memory.
- QA shots print `[perf] fps draw_calls objects primitives process_ms physics_ms nodes skinned`.
  Extra flags: `--census` (who owns visible skeletons), `--drawcensus` (visible geometry by owner/mesh, tris),
  `--ablate[=script.gd/Node]` (hide each child in turn, prints draws/prims it costs).
- xvfb note: fps and process_ms are software-render frame time (TIME_PROCESS is the whole frame step), not script cost. Use draws/prims/skinned.

### Changes
1. Town houses: baked LOD2 (voxel remesh + decimate + texture bake, tools/meshy/bake_lod.py, 1.4k tris, 1 material) for house_town_a..d (assets/generated/townhouse_*_lod2.glb, registered in Assets.BUILDINGS). The old docs were off: the townhouse is 13.2k tris LOD0 / 4.5k LOD1, not 4.5k single LOD. house_1..16 already had LOD1/LOD2. On LOW, townhouses now draw LOD1 (<25 m) then LOD2. Cells with a LOD2 are 60 m (MID_CELL) so LOD switches per neighbourhood. Surface atlas merge was not done (LOD2 is already 1 draw; LOD1 stays 4 surfaces).
2. Stations/props: `Assets.static_model(path)` returns one MeshInstance3D with the GLB parts merged per material (auto mesh LODs kept), falling back to the scene for skeleton/light/anim/named-empty scenes. Notice board went from 24 draws to 5; used for station props and for all RegionDressing parts (except wind-shaded nature). Town-wide MultiMeshes (door clutter ~190 crates/barrels/sacks, lamp posts, planters, fields) are now per-cell (40/60 m) so they are frustum-culled per neighbourhood. Town walls, gates, towers: 70 m cells with LOD1 (and LOD2 for gates) stages (Assets.BUILDINGS wall/wall_tower/wall_gate now list them).
3. Characters: DistanceCull for gate guards, station NPCs and stronghold guards now at 80 m (LOW 44 m); critter cull 40 m small / 100 m large (LOW 22 / 55 m). Skinned: gate 37 -> 17. No decimated character LOD was made (would need re-rigging the shared skeleton); impostor swap is still open.
4. Terrain: every chunk also builds a 512-tri ground mesh (grid step 4 m) with a 4 m skirt; chunks whose centre is past 110 m swap to it (visibility range). Seams checked in aerial/city shots, no cracks.
5. Shadows: on LOW, MultiMesh props under 1.6 m no longer cast shadows (not visible in the draw/prim counters, which exclude shadow passes).
6. Campus fix: `RegionDressing._lod_pair` judged Meshy pieces by their raw import size (~2.4 m, they are scaled x4-9 afterwards), so a 9 m guild hall got a 120 m cull range and no shadows. It now takes the fit height. Meshy pieces with lod2/lod3 files also get those far stages (90 / 200 / 400 m). New QA shot: `--shot=academy [--dist=60 --rot=0.5 --pitch=-0.12]`.
Tooling: `--drawcensus` keys now show material names; `--ablate` groups MultiMesh cells by material + range.
