# Items, recipes, shops, loot

- **Source of truth:** `kingdom/data/items/*.json` and `data/recipes/*.json`, generated by `python3 tools/items/build.py` (run from `kingdom/`). Edit the generator tables, not the JSON. The design doc is `docs/design/ITEMS_R1.md`.
- **Loader:** `scripts/sim/items_db.gd` merges the JSON into the old item DB, so old ids, prices and stats never change. Region 1 caps items at level 60, with 11 legendary uniques only.
- **Loot API:** `ItemsDB.loot_table(tier, theme)`, `roll_loot(tier, theme, rng, bonus_rolls)`, `monster_drops(species, rng, extra_roll)`. Tiers run 1-5; themes include `tower`, `boss`, `cave`, `crypt`, `hideout`.
- **Shops:** `scripts/ui/shop_screen.gd`. Markets are stocked in `economy._build_market` from the settlement's kind and size; pass `s["idents"]` for identity shops.
- **Icons:** `assets/ui/icons/` (one SVG per item). Visuals: `ItemsDB.visual_node(id)` maps to free models in `assets/items/` (credits in CREDITS.md).
- **Crafting:** `crafting.gd` handles merge, `salvage` and tool tier bonuses. Stations: oven, brew vat, loom and jeweller's bench, or an existing fallback station.

## Hooks not wired yet (check before assuming)
- Equipment visuals: attach `visual_node` when `Life.equipment.changed` fires.
- `Life.apply_item_effect(id, info) -> String` for pills, scrolls, coatings and recall. Until it exists those items are refused.
- `req_level` isn't enforced in `equip()`.
- Spoilage data is unused (nothing ages stacks). `plant()` doesn't consume seeds.
- Crafting screen rows show blank white icons for many recipes.
